# Author affiliations

Reference table containing information about authors' affiliations,
including regional office acronyms, addresses, and the standardized way
to reference each office in
[`create_template()`](nmfs-ost.github.io/asar/reference/create_template.md)
when specifying the `authors` argument.

## Usage

``` r
affiliation_info
```

## Format

A data frame with rows and columns.
